📋 Процесс

Запустить за 4 шага

Никаких сложных настроек. Зарегистрируйся, подключи аккаунт и запусти автопилот.

1

Регистрация

Заходишь на сайт, регистрируешься через Telegram. Подтверждаешь код от нашего бота — и ты внутри.

2

Подключи Telegram

Вводишь свой API ID и API Hash (инструкция внутри). Авторизуешься через код — система работает от твоего аккаунта.

3

Настрой проект

Выбираешь каналы-доноры, свой канал куда постить, пишешь промт как должен выглядеть контент.

4

Запусти и забудь

Нажимаешь «Старт» — GhostPost работает 24/7 сам. Ты занимаешься своими делами, канал растёт.

❓ Вопросы

Частые вопросы

Это легально? Не заблокируют ли мой аккаунт?+
Парсинг публичных каналов — обычное чтение информации. Мы используем официальное Telegram API и соблюдаем лимиты. При разумном интервале (от 1 часа) риск минимален.
Нужно ли оставлять компьютер включённым?+
Нет! GhostPost работает на наших серверах 24/7. После настройки тебе не нужно ничего держать включённым — система работает сама в облаке.
Что такое API ID и API Hash? Где взять?+
Ключи доступа к Telegram API — нужны чтобы система работала от имени твоего аккаунта. Получить бесплатно на my.telegram.org за 2 минуты. Внутри платформы есть пошаговая инструкция.
Мои данные в безопасности?+
API Hash хранится в зашифрованном виде. Мы не имеем доступа к вашим сообщениям и не передаём данные третьим лицам. Можно удалить аккаунт и все данные в любой момент.
Можно использовать для интернет-магазина?+
Да! Модуль «Интернет магазин» специально для этого. Система копирует товары, переписывает описание, добавляет наценку к цене и публикует с фотографиями.
