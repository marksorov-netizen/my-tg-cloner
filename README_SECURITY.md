# 🔐 Руководство по безопасности — MyBotAi11

## ⚠️ КРИТИЧЕСКИ ВАЖНО

Этот проект использует **Telegram User API (Telethon)** — это не Bot API.  
Вы авторизуетесь от имени **реального личного аккаунта Telegram**.  
Утечка credentials = потеря доступа к аккаунту + возможный бан.

---

## Шаг 1: Получите api_id и api_hash

1. Откройте [my.telegram.org](https://my.telegram.org) в браузере
2. Войдите через SMS-код на ваш номер телефона
3. Выберите **"API development tools"**
4. Заполните форму (название приложения — любое, платформа — Other)
5. Скопируйте `api_id` (число) и `api_hash` (строка из 32 символов)

> ⚠️ **Никому не передавайте api_id/api_hash!** С ними можно авторизоваться от вашего имени.

---

## Шаг 2: Настройте .env файл

```bash
# Скопируйте шаблон
cp .env.example .env

# Откройте .env и вставьте реальные значения
# TELEGRAM_API_ID=12345678
# TELEGRAM_API_HASH=abc123def456...
# GEMINI_API_KEY=AIza...
```

| Хранить ключи в коде | Всегда через переменные окружения |

## Риски использования Telethon (User API)

### 🔴 Бан аккаунта
Telegram может заблокировать аккаунт за:
- Слишком частые запросы (FloodWait)
- Парсинг большого количества публичных каналов
- Отправку спама через аккаунт

**Рекомендация:** Используйте отдельный аккаунт (вторую симкарту) только для парсинга.

### 🟡 Ограничения скорости
- Не делайте более **1 запроса в секунду** к Telegram API
- При `FloodWaitError` — ждите столько секунд, сколько указано в ошибке
- Для `iter_messages` используйте задержку между постами

### 🟡 Приватные каналы
- Ваш аккаунт должен быть **подписан** на канал-донор
- Без подписки `get_entity()` вернёт ошибку `ChannelPrivateError`

## Файлы, которые НИКОГДА не должны попасть в git

```
.env                    # API ключи и secrets
*.session               # Telegram сессии (авторизация аккаунта)
*.session-journal       # Журнал сессии
user_session.json       # Сохранённая сессия этого проекта
```

Убедитесь, что они есть в `.gitignore` (уже добавлены в этом проекте).

---

## Если ваши credentials уже попали в git

1. **Немедленно** зайдите на [my.telegram.org](https://my.telegram.org) и **сбросьте** api_hash (создайте новое приложение)
2. Завершите все активные Telegram-сессии через `Настройки → Устройства → Завершить все сессии`
3. Смените пароль 2FA, если он был установлен
4. Используйте `git filter-branch` или [BFG Repo Cleaner](https://rtyley.github.io/bfg-repo-cleaner/) для очистки истории
